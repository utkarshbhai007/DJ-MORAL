
# Gallery Images

This folder contains the gallery images for DJ Moral's website.

## How to add images:

1. **Add your images to this folder** (`public/images/gallery/`)
2. **Name your images**: `image1.jpg`, `image2.jpg`, `image3.jpg`, etc.
3. **Supported formats**: .jpg, .jpeg, .png, .webp
4. **Recommended size**: 800x800px or larger (square aspect ratio works best)
5. **File size**: Keep under 2MB per image for faster loading

## To add more images:

If you want to add more than 12 images, edit the `src/components/Gallery.tsx` file and add more entries to the `images` array following the same pattern.

## Note:

- Images that are not found will show a placeholder
- Make sure your image files are named exactly as specified above
- The gallery will automatically display all available images
